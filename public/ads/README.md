# Ad space / مساحة الإعلانات

Drop ad images in this folder named `1.png`, `2.png`, `3.jpg` … (up to 8, also .jpeg/.webp).
The leaderboard finds them automatically and rotates one every 10 seconds.
Delete `1.png` (the placeholder) once you add real ads. No code changes needed — just push.

ضع صور الإعلانات هنا بأسماء `1.png`، `2.png`، `3.jpg` … (حتى 8 صور).
تظهر تلقائيًا في لوحة الصدارة وتتبدل كل ١٠ ثوانٍ.
احذف `1.png` (الصورة التجريبية) عند إضافة إعلانات حقيقية.
